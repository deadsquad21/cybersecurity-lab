# Lab: HTTP Security Headers

## Environment
Use a local demo application, a saved header sample, or a website you own / are authorized to assess.

## Objective
Understand how defensive HTTP response headers reduce common browser-side risks.

## Exercise
1. Capture the response headers.
2. Run the included analyzer.
3. Review missing/recommended controls.
4. Add controls in the lab environment.
5. Run the analyzer again and document the change.

## Evidence
Store only sanitized screenshots or header samples in `evidence/`.

## Expected Learning
Be able to explain what each header contributes, its limitations, and why a header alone does not replace secure application design.
