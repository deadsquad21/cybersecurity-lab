# Deployment Security Checklist

- [ ] Production secrets come from a secret manager or protected environment variables
- [ ] Debug mode disabled
- [ ] Secure cookie settings enabled
- [ ] TLS terminated by a trusted, maintained component
- [ ] Security headers configured at application or edge
- [ ] Default credentials removed
- [ ] Admin interfaces restricted
- [ ] Backups tested
- [ ] Monitoring and alerting defined
- [ ] Rollback plan documented
