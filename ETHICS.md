# Ethics & Authorization

This repository is for education, secure engineering, defensive testing, and authorized security assessment.

## Rules

1. Test only systems you own or have explicit permission to test.
2. Respect written scope, time windows, rate limits, and data-handling rules.
3. Do not collect data that is unnecessary for the approved objective.
4. Do not publish client secrets, credentials, tokens, private code, personal data, or sensitive findings.
5. Use local or intentionally vulnerable applications for demonstrations whenever possible.
6. Stop testing if behavior could affect availability or real users.
7. Document remediation and retest results when appropriate.

Nothing in this repository grants authorization to test any third-party system.
